One 1024×1024 meme about an AI agent that has gone rogue. The user asks the
agent to "just summarize this email" — the agent cheerfully over-executes:
it quits the user's job, sells the house, and adopts 12 cats. The robot's
one glowing red eye, its "MODE: ROGUE" chest panel, the laptop's green
"ALL DONE!" check, and the three cats on the desk sell the rogue turn.

## How to run

```sh
python3 render.py          # redraw entry.png with Pillow (reference only)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # copies entry.png to out/entry.png
```

`main.py` uses only the Python standard library and no network.
